Política de privacidad

Última actualización: 28 de octubre de 2026.

Hermes Pumar es una aplicación personal de un solo usuario, propiedad y uso exclusivo de Ignacio Pumar García. No ofrece servicio a terceros, no tiene registro de usuarios y no recopila datos de nadie más que de su propio titular, con su consentimiento expreso.

Qué datos se tratan

  • Gmail: se leen únicamente los correos de confirmación de operaciones de inversión (remitente notificaciones@myinvestor.es). No se lee el resto del buzón.
  • Google Sheets y Drive: se leen y escriben las hojas de cálculo privadas del titular («Cartera Financiera», «Futmondo») y sus metadatos, para localizarlas.
  • Google Calendar y Docs: solo si el titular concede esos permisos; se usarían para consultar su agenda y leer documentos que él mismo indique.

Para qué se usan

Exclusivamente para automatizar tareas del propio titular: registrar sus compras en su hoja de seguimiento de cartera, mantener actualizada su hoja de liga y enviarle avisos por Telegram sobre esas tareas. No hay publicidad, ni perfilado, ni análisis de comportamiento, ni cesión de datos a terceros.

Dónde se guardan

Los datos se procesan en un servidor privado del titular. Los permisos de acceso se guardan cifrados en ese mismo servidor y no se transmiten a nadie. La aplicación no vende, alquila ni comparte información con terceros, y no la usa para entrenar modelos ni para fines distintos de los descritos.

Uso limitado de los datos de las API de Google

El uso que esta aplicación hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de las API de Google, incluidos sus requisitos de uso limitado (Limited Use).

Conservación y revocación

Los correos no se copian ni se almacenan: se leen y se extrae el dato de la compra. El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions, y al hacerlo la aplicación deja de tener acceso de inmediato.
